Documentación del Programa

Este sistema fue desarrollado como parte del curso de Introducción a Programación y Computación 2.

Descripción

El programa gestiona clientes, recursos, configuraciones, instancias y facturación para una empresa tecnológica. Permite importar datos desde archivos XML, calcular costos por horas de uso y generar reportes en PDF o XML.

Características principales

  • Gestión de clientes y recursos
  • Importación de configuraciones desde XML
  • Cálculo automático de costos y horas
  • Generación de facturas en PDF y XML
  • Interfaz con diseño oscuro y moderno
